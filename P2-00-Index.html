Design tokens v1.0 →Component library →Large display (1920) →Compact mobile brief (390) →State gallery →

Phase 3 restyles the six template components with the approved tokens, so all routes changed together while the information architecture and content stayed the same. Every route is a thin data file rendered by one of the six templates (TplA–TplF), so no route has its own layout. Lens depth (Owner summary, Core Group comparative, Entity operational) comes from density tokens. The shell, scope bar, trust legend, status strip, ≤6-card limit (enforced in code) and state handling come from the template. All values are SYNTHETIC; thresholds and limits are PLACEHOLDER. Open any route in Play: the global navigation, KPI cards, links and decision buttons are clickable.
